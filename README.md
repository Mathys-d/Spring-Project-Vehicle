# Spring Project — Vehicle Service

Ce projet est un **microservice Spring Boot** qui expose une API REST pour gérer des entités **Vehicle** (véhicules). Il fait partie d’une architecture microservices et peut s’enregistrer auprès d’un **Eureka Server** pour la découverte de services.

---

## 🌟 Fonctionnalités

- Service REST pour manipuler des véhicules
- CRUD (Create, Read, Update, Delete) basique des véhicules
- Possibilité de s’enregistrer auprès d’un serveur Eureka
- Exposition d’endpoints REST simples

---

## ⚙️ Prérequis

Avant de lancer ce microservice, assure‑toi d’avoir :

- **Java JDK 17 ou supérieur**
- **Maven**
- Un **Eureka Server** en cours d’exécution si tu veux activer l’enregistrement
- Un IDE (IntelliJ, Eclipse, VS Code) ou un terminal
